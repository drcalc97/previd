## 1. Timed Up and Go (TUG) — CORE

**Sources.** Original: Podsiadlo & Richardson 1991 [1], a timed modification of Mathias 1986 [2]. Setup details come from later protocol sheets [3]; the original full text was not read.

| Item | Finding | Category / status |
|---|---|---|
| Task | Rise from armchair, walk 3 m, turn, walk back, sit down. Result is total time in seconds. | (a) PARTLY [1] |
| Start event | Most commonly cited: clock starts on the examiner's "go" cue. Variant (UNVERIFIED, recalled): start at first body movement. | (b); "go" PARTLY [3] |
| Stop event | Most commonly cited: patient's buttocks touch the seat / patient is seated. Variant (UNVERIFIED): patient's back against chair back. | (b); PARTLY [3] |
| Chair | Standard-height chair, seat about 46 cm, arm height 65 cm or 67 cm (sources disagree). Armchair in the original. Whether arms may be used to push up is not confirmed. | (b) PARTLY [3] |
| Course | 3 m marked line/cone; turn direction and turn type (e.g. around cone) not confirmed. | UNVERIFIED |
| Footwear / aids | Regular footwear and customary walking aid allowed; aid recorded. | (b) PARTLY [3] |
| Pace | "Comfortable and safe pace" is common wording in later guides; not confirmed in original. | UNVERIFIED |
| Trials | One practice trial not scored, then timed trial(s). Which timed trial is used (single, mean, best) is not confirmed. | PARTLY [3]; remainder UNVERIFIED |
| Unable / invalid | No source retrieved states a rule. Proposed PreVid recording only (see SCORING.md): unable-to-perform, aid used, assistance given, stopped, video-invalid. | (c) PreVid convention |
| Safety | Guarding/supervision close by, aid within reach; stop if unsafe. Clinician judgement required. Specific stop criteria not retrieved. | UNVERIFIED |
| Standard script | Not retrieved; do not reproduce. Original paper copyright: publisher (Wiley/AGS). | Flag |
| Reliability | Original abstract reports high inter- and intra-rater reliability and correlation with Berg Balance Scale and gait speed [1]. A CLSA community sample reports ICC about 0.80 [24]. MDC values not retrieved. | PARTLY |
| Video suitability | Suitable for manual video timing if the chair, 3 m line and full body are in frame; the clock events must be visually unambiguous. Seat-contact is harder to see than "go" audio cue. | PreVid proposal |
| Evidence note (perioperative) | Used as a bedside test in surgical populations; systematic reviews found limited value for risk prediction and no single superior test [22]. A TUG over 20 s was associated with higher long-term mortality after TAVI in one review (different population; secondary summary; not used by PreVid). The commonly quoted 13.5 s fall-risk cut-off could NOT be confirmed. | PARTLY |

## 2. Five-Times Sit-to-Stand (5xSTS) — CORE

Five repetitions. Sources: Csuka & McCarty 1985 [4], Whitney 2005 [5], Bohannon 2006 [6], protocol sheets [7].

| Item | Finding | Category / status |
|---|---|---|
| Task | Stand fully up and sit down five times as fast as possible, arms folded across chest. Result: total time in seconds. | (a) PARTLY [7] |
| Start event | Clock starts at "Go" command (SRA protocol). | PARTLY [7] |
| Stop event | **Variants differ:** (i) buttocks touch seat after 5th repetition (Csuka/Bohannon/SRA-type); (ii) full upright standing on 5th repetition (SPPB). Most common in rehabilitation literature is (i). | (b) PARTLY [7] |
| Chair | Armless, firm. Seat heights in literature: 43, 44.5 (Csuka & McCarty), 45, 46 cm. Often placed against a wall. | PARTLY [4][7] |
| Arms | Folded across chest; "stand up completely and make firm contact when sitting" per one study. | PARTLY [7] |
| Trials | Not confirmed (single timed trial after demonstration is common; UNVERIFIED). | UNVERIFIED |
| Unable / invalid | Cannot do without using arms: record "unable"/"arms used" (SPPB scores 0 for the chair component in that case; see section 4). No other source rule retrieved. | PARTLY |
| Safety | Chair stable (against wall), guard if balance concern; stop if symptoms. | UNVERIFIED |
| Reliability | Goldberg 2012 [8] (older women: high ICC, low SEM; MDC not retrieved); meta-analysis [9] reports high test-retest reliability, pooled values not retrieved. | PARTLY |
| Video suitability | Suitable: side-on view; stop event must be defined (seat contact vs upright). Repetition count verifiable on video. | PreVid proposal |
| Evidence note | No perioperative 5xSTS evidence was retrieved. Do not assume any threshold. | UNVERIFIED |
| Non-interchangeability | Standalone 5xSTS (typically stops at seat contact, may allow different chair height, no prior single-stand screen) is NOT interchangeable with the SPPB chair-stand component (full upright stop; single-stand screen first; banded score). | PARTLY |

## 3. Four-Metre Gait Speed — CORE

Sources: Studenski 2011 [13]; Guralnik 1994 [10] for the SPPB 4 m walk; Peel 2013 [14] UNVERIFIED.

| Item | Finding | Category / status |
|---|---|---|
| Task | Walk 4 m at usual pace; speed = 4 / time in m/s. | (a) PARTLY [13] |
| Start | Standing start (Studenski pooled studies: all standing start; instruction: usual pace, "as if walking down the street"). Moving start (with run-in zone) is used in other literature: UNVERIFIED. | PARTLY [13] |
| Clock events | Typically start when the first foot/torso crosses the start line or on "go"; stop when the torso/foot crosses the end line. Exact event is NOT confirmed by a retrieved source. | UNVERIFIED |
| Acceleration / deceleration | Some protocols add 1-2 m before the start line and beyond the finish line; not confirmed. Decide with clinician. | UNVERIFIED |
| Distance variants | Pooled studies used 8 ft to 6 m, converted to 4 m equivalents; 4 m speed = -0.0341 + (6 m speed x 0.9816), R2 0.93, from 61 people [13]. | PARTLY |
| Trials | SPPB: two walks, faster time used (Harvard/SRA forms) [11]. Studenski: not confirmed. | PARTLY |
| Aids | Usual walking aid allowed in SPPB-type protocols; record aid. | UNVERIFIED |
| Unable | SPPB scores gait component 0 if unable [11]. Standalone rule: record "unable" (PreVid proposal). | PARTLY |
| Safety | Guard walking; clear 4 m plus run-off; stop if unsafe. | UNVERIFIED |
| Evidence note | Gait speed associated with survival in community older adults (pooled HR 0.88 per 0.1 m/s) [13]. Perioperative: one prospective cohort of frail abdominal surgery patients used 6 m gait speed (single centre) and a scoping review quoted a 5 m walk of 6 s or more linked with higher mortality; TAVI meta-analysis quoted below 0.83 m/s. All different populations and protocols; none adopted by PreVid. | PARTLY |
| Video suitability | Suitable with fixed side-on camera perpendicular to the track and visible floor markers. Frame rate limits timing resolution. | PreVid proposal |
| Non-interchangeability | Studenski conversion formula applies to usual-pace standing-start walks; SPPB gait component uses banded points of its own; a moving-start speed is typically faster than a standing-start speed. | PARTLY |

## 4. Short Physical Performance Battery (SPPB) — ADDITIONAL

Sources: Guralnik 1994 [10]; NIA/other protocol and scoring sheets [11]. NIA ENRGISE form text could not be read in scoring detail. Scoring tables are in SCORING.md.

| Item | Finding | Category / status |
|---|---|---|
| Structure | Three components, each scored 0-4: standing balance, 4 m gait speed, five chair stands; total 0-12. | (a) PARTLY [10][11] |
| Balance | Side-by-side, semi-tandem, tandem, 10 s each maximum. Progression stops when a position is not held. Tandem partial credit for 3-9.99 s. Additive-point presentation (1, 1, up to 2) and ordinal presentation (0-4) give the same totals. | PARTLY |
| Gait | 4 m, usual pace, two trials, faster used; unable scores 0. Start/stop events and aids: see protocol sheet; not retrieved. | PARTLY |
| Chair stands | Single stand screen without arms first; unable then stop and score 0. If able, five stands as fast as possible. Stop event for the five-stand timing: full upright on 5th stand (SPPB variant). | PARTLY [7][11] |
| Unable / not attempted | Component scores 0 (gait, chair); balance scored from what was held. Source-specific reason codes (unable, unsafe, declined) exist in some forms [11]. | PARTLY |
| Boundary discrepancies | Gait 2-point band is written 6.21-8.70 s (SRA, Harvard) or "6.20" in other sheets; 4.82 inclusive/exclusive varies; chair times at or above 60 s scored 0 (one source) vs 1 (another). Official NIA sheet must be consulted. | PARTLY |
| Population-specific scales | A 2026 nursing-home study proposed revised bands (e.g. 5.65 s and 10.80 s). Not standard scoring. | PARTLY [12] |
| Safety | Guard each balance position; be ready to catch; stop on unsafe performance; no specific stop criteria retrieved. | UNVERIFIED |
| Licensing | Official NIA/Guralnik scoring sheets are US-government-hosted and widely used; reuse terms not confirmed. | UNVERIFIED |
| Evidence note | Guralnik 1994: association with self-reported disability and prediction of mortality and nursing home admission in community older adults [10]. No perioperative SPPB evidence or threshold was retrieved. | PARTLY |
| Video suitability | Balance holds are timeable on video (start when feet in position and support released; stop when balance lost/10 s). Event definitions need clinician confirmation. | PreVid proposal |

## 5. Six-Minute Walk Test (6MWT) — ADDITIONAL

Sources: ATS 2002 [15]; ERS/ATS 2014 technical standard [16]. **Only secondary summaries were retrieved; most operational details below are UNVERIFIED.** ATS holds the copyright to the 2002 statement; do not reproduce scripts.

| Item | Finding | Category / status |
|---|---|---|
| Task | Walk as far as possible in 6 minutes along a flat 30 m corridor; result is total distance in metres. | (a) PARTLY [15] |
| Course | 30 m corridor, minimally trafficked; turnaround cones. Length is marked; lap counter used. Cone spacing detail UNVERIFIED. | PARTLY |
| Encouragement | Standardised phrases at one-minute intervals; tone even; no other words or body language. Encouragement can change distance by up to 30% per one summary. Exact phrase wording not retrieved. Some trials use "non-encouraged" variants (conflicts with ATS). | PARTLY / (b) |
| Rest | Participants may slow, stop and rest, resuming when able; whether the clock keeps running (ATS: yes, to our recollection) UNVERIFIED. Intermittent rest allowed per a sponsor protocol. | UNVERIFIED |
| Partial lap | Distance = full lengths x length + final partial length measured to nearest metre (recollection). | UNVERIFIED |
| Practice test | Not confirmed; ATS 2002 and 2014 differ (2014 notes a learning effect, UNVERIFIED). | UNVERIFIED |
| Walking aids / O2 | Aid permitted and recorded (UNVERIFIED). | UNVERIFIED |
| Absolute contraindications | Unstable angina or MI in previous month (per ATS excerpt). 2014: contraindications aligned with those for CPET. | PARTLY |
| Relative contraindications | Resting heart rate, blood pressure thresholds exist in ATS 2002; values NOT verified here. | UNVERIFIED |
| Stop immediately | Chest pain, intolerable dyspnoea, leg cramps, staggering, diaphoresis, pale or ashen appearance. SpO2 below 80% in standard respiratory protocols (not relevant when no oximeter). | PARTLY |
| Supervision | Trained assessor present; emergency equipment/response. A self-administered remote 6MWT is outside the sources reviewed. A clinician must decide whether remote video supervision is acceptable. | UNVERIFIED |
| Evidence note | Perioperative use: METS 6MWT substudy found the relationship between 6MWD and complications uncertain [21]; abdominal-surgery review found limited value for risk prediction [22]. | PARTLY / UNVERIFIED |
| Reliability | Not retrieved. | UNVERIFIED |
| Video suitability | Distance counting from video is possible with lap markers and a visible clock, but safety supervision requirements are the dominant issue. Timing is fixed (6 min), so the measure is distance, not time. | PreVid proposal |

## 6. Duke Activity Status Index (DASI) — ADDITIONAL

Sources: Hlatky 1989 [17]; secondary weight tables [18]; licensing [19]; perioperative [20].

| Item | Finding | Category / status |
|---|---|---|
| Nature | Self-administered 12-item yes/no questionnaire of activities; not a performance test; no video component. | (a) PARTLY |
| Scoring | Weighted sum of "yes" answers: 0 to 58.2. Weights in SCORING.md; sum check computed = 58.2. | PARTLY [18] |
| VO2 equation | Estimated peak VO2 = 0.43 x DASI + 9.6. Unit: mL/kg/min per one calculator source; one other source wrote mL/min, so the unit remains partly unresolved. Attributed to Hlatky 1989 by secondary sources only. METs = VO2 / 3.5. | PARTLY |
| Derivation population | Derivation: 50 subjects undergoing exercise testing with peak VO2 (Spearman 0.80); validation: 50 independent subjects (Spearman 0.58). "Referred for treadmill" not confirmed. Not a surgical population. | PARTLY [17] |
| Missing answers | Source rule not retrieved. | UNVERIFIED |
| **Licensing / item wording** | **UNCLEAR. DO NOT reproduce or paraphrase the item wording in PreVid until resolved.** Pattern Health is described by one search result as the "exclusive licensor" offering paper, eCOA and app formats; the copyright holder was not identified. Duke website reuse policies do not grant rights to the instrument. Free copies online carry no licence statement. The owner has instructed to stop and flag. **Action needed from owner: contact Pattern Health (and the AJC publisher for the paper) to obtain licence terms before any in-software use.** Weights alone (numbers) are given here only so scoring can be specified and tested; they are not a substitute for a licence. | BLOCKER |
| Item adaptation | Adapted items exist in the literature (e.g. alternative for the sexual activity item) [25]; adaptation likely needs permission and revalidation. | UNVERIFIED |
| Evidence note | METS cohort (1,546 adults 40+ at elevated cardiac risk, inpatient non-cardiac surgery): DASI below 34 associated with higher odds of 30-day death or MI, non-linear; reported to identify risk of myocardial injury/MI, moderate-to-severe complications and new disability in that cohort. A related summary says DASI did not accurately identify patients who performed poorly on formal exercise testing. **Population-specific, not adopted by PreVid; no risk category will be shown.** | PARTLY [20] |
| Video suitability | Not applicable. Reliability data not retrieved. | n/a |
